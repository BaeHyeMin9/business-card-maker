# 나만의 명함 만들기

이름과 연락처, 나를 소개하는 문장을 입력하며 나만의 명함을 구성하는 웹 프로젝트입니다. 왼쪽 입력창에서 내용을 바꾸면 오른쪽 명함 미리보기에 바로 반영됩니다.

[명함 만들기 바로가기](https://baehyemin9.github.io/business-card-maker/) · [프로젝트 상세 설명](docs/README.md)

## 주요 기능

- **기본 정보 입력**: 이름, 학과, 희망 분야 설정
- **연락처 입력**: 전화번호와 이메일 작성
- **한 줄 소개 작성**: 나를 표현하는 짧은 문장 입력
- **실시간 미리보기**: 입력한 내용을 명함에서 바로 확인

## 사용 방법

1. 위의 실행 링크를 엽니다.
2. 이름과 학과, 희망 분야를 입력합니다.
3. 전화번호, 이메일, 한 줄 소개를 작성합니다.
4. 명함 미리보기를 확인하며 내용을 수정합니다.

입력 내용을 저장하거나 명함을 이미지로 내려받는 기능은 현재 포함되어 있지 않습니다. 새로고침하면 처음 화면으로 돌아갑니다.

## 사용 기술

| 기술 | 역할 |
| --- | --- |
| HTML | 입력 양식과 명함의 구조 작성 |
| CSS | 색상, 글꼴, 입력창과 명함의 배치 구성 |
| JavaScript | 입력값을 명함 미리보기에 반영 |

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 명함 입력 양식과 미리보기 화면 |
| `css/style.css` | 화면과 명함의 디자인 |
| `js/script.js` | 입력값과 미리보기를 연결하는 동작 |
| `docs/README.md` | 주요 기능과 구현 방식에 대한 상세 설명 |

## 내 컴퓨터에서 실행하기

저장소의 파일을 내려받아 압축을 푼 다음 `index.html`을 브라우저에서 열면 됩니다. 별도 설치나 빌드 과정은 필요하지 않습니다. Google Fonts의 웹 글꼴을 불러올 때는 인터넷 연결이 필요하며, 연결되지 않으면 대체 글꼴로 표시됩니다.
