# 프로젝트 상세 설명

[명함 만들기 실행하기](https://baehyemin9.github.io/business-card-maker/) · [처음으로 돌아가기](../README.md)

## 어떤 프로젝트인가요?

사용자가 자기소개 정보를 입력하고, 명함 형태로 정리된 결과를 바로 확인하는 웹 기초 실습 프로젝트입니다. 입력 양식과 명함 미리보기를 연결하여 HTML, CSS, JavaScript가 함께 동작하는 과정을 연습합니다.

## 입력할 수 있는 정보

| 항목 | 입력 방식 | 명함에 표시되는 내용 |
| --- | --- | --- |
| 이름 | 글자 입력 | 명함의 이름 |
| 학과 | 목록에서 선택 | 이름 위의 학과 |
| 희망 분야 | 글자 입력 | 이름 아래의 희망 분야 |
| 연락처 | 전화번호 입력 | 전화 아이콘 옆의 번호 |
| 이메일 | 이메일 입력 | 우편 아이콘 옆의 주소 |
| 한 줄 소개 | 문장 입력 | 명함 가운데의 소개 문구 |

학과 목록에는 컴퓨터공학과, 소프트웨어학과, 인공지능학과, 컴퓨터소프트웨어공학과, 데이터사이언스학과, 게임콘텐츠학과가 있습니다.

## 어떻게 동작하나요?

1. HTML에서 입력창과 명함에 표시할 자리를 만듭니다.
2. JavaScript의 `querySelector()`로 입력창과 표시할 자리를 찾습니다.
3. 입력창에 `input` 이벤트를 등록합니다.
4. 사용자가 입력한 `value`를 명함 요소의 `textContent`에 넣어 화면을 갱신합니다.

예를 들어 이름 입력창의 값이 바뀌면 `.card-name` 요소의 글자도 바뀝니다. 학과와 연락처, 소개 문장도 같은 방식으로 연결되어 있습니다.

## 화면 디자인

- 남색 바탕의 명함에 노란색 강조 색상을 사용했습니다.
- 입력 영역을 기본 정보, 연락처, 한 줄 소개로 나누었습니다.
- 화면 너비가 부족하면 입력 영역과 미리보기가 다음 줄로 배치됩니다.
- 소개 입력창에서 줄을 바꾸면 명함에도 줄바꿈이 반영됩니다.

## 현재 제공 범위

브라우저에서 입력하고 결과를 미리 보는 기능을 제공합니다. 입력 내용의 영구 저장, 이미지·PDF 다운로드, 명함 공유 기능은 포함되어 있지 않습니다.

## 파일별 역할

| 경로 | 역할 |
| --- | --- |
| [`index.html`](../index.html) | 제목, 입력 양식, 미리보기, 하단 정보 구성 |
| [`css/style.css`](../css/style.css) | 색상, 여백, 글꼴, 명함 모양과 화면 배치 설정 |
| [`js/script.js`](../js/script.js) | 입력한 정보가 미리보기에 반영되도록 연결 |
